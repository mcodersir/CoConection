# امنیت و شفافیت Koyra One

Koyra One برای اعتماد کاربر این اصول را دارد:

## بدون obfuscation

کد `server.js` خواناست. هیچ بخش رمزگذاری‌شده یا مبهم ندارد.

## بدون dependency خارجی

برای اجرای سرور از پکیج خارجی استفاده نشده. فقط ماژول‌های داخلی Node.js استفاده شده‌اند:

```text
http
net
crypto
url
```

## کلیدها داخل کد نیستند

مقدارهای خصوصی باید از Environment Variables بیایند:

```text
KOYRA_KEY
KOYRA_UUID
KOYRA_SUB_TOKEN
KOYRA_ADMIN_KEY
```

## پیشنهاد برای استفاده شخصی

- `KOYRA_KEY` بلند و خصوصی بگذار.
- اگر لینک subscription را برای کسی نمی‌فرستی، باز هم `KOYRA_SUB_TOKEN` بگذار.
- اگر سرویس را لازم نداری، آن را خاموش یا حذف کن.
- برای تعداد کاربر بالا از این نسخه استفاده نکن.

## محدودیت امنیتی نسخه ۱

این نسخه پنل کاربری، سیستم مدیریت کاربر، محدودیت مصرف و لاگ پیشرفته ندارد. برای یک نفر و مصرف شخصی طراحی شده است.
