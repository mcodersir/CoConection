راهنمای کانفیگ سفارشی

  • حجم 0 = حجم نامحدود
  • زمان 0 = زمان نامحدود
  • نام کانفیگ برای شناسایی در کلاینت استفاده می‌شود
  • IP تمیز اختیاری است؛ اگر وارد نکنی از Worker اصلی استفاده می‌شود
  • هر کانفیگ سفارشی UUID جداگانه دارد
کانفیگ‌های سفارشی مستقیماً از Worker تو استفاده می‌کنند و محدودیت‌ها در نام کانفیگ ذکر می‌شوند.
